# 🤖 Test Automation ROI Calculator

A visual, interactive tool for QA engineers and development teams to calculate the Return on Investment (ROI) of test automation.

## 🎯 Purpose
Not every manual test should be automated. This calculator helps you make data-driven decisions by comparing the time spent on manual testing versus the time required to develop and maintain an automated script.

## ✨ Features
* **Instant Calculation:** Real-time updates as you type.
* **Smart Recommendations:** Automatically suggests if a test is "Highly Recommended", "Worth Considering", or "Low Priority" to automate based on the Break-even point (in months).
* **Team Savings:** Calculates total estimated hours saved per month across the team.
* **Modern UI:** Built with Tailwind CSS for a clean, responsive layout.

## 🚀 How to Use (GitHub Pages)
1. Fork or clone this repository.
2. Go to your repository **Settings** > **Pages**.
3. Under "Source", select the `main` branch.
4. Save and wait a minute. Your calculator is now live!

## 🛠️ Tech Stack
* HTML5
* Tailwind CSS (via CDN)
* Alpine.js (for lightweight reactivity)
